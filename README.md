# إدارة المياه | Water Management

مستودع مشروع **إدارة المياه** لإدارة الغواطس وتوزيع المياه، مع تطبيق ميداني للهاتف، ولوحة إدارة ويب، وبوابة محدودة للمشتركين، وخلفية مشتركة مبنية على Supabase.

> **حالة المستندات:** الملفات داخل `docs/` تمثل التصور والخطة والقرارات المرجعية للمشروع. وجود المواصفة في المستودع لا يعني أن جميع وظائفها منفذة في الشيفرة الحالية.

## القرارات الأساسية

- تطبيق الهاتف: Expo + React Native + TypeScript.
- لوحة الإدارة وبوابة المشترك: Next.js + TypeScript.
- الخلفية: Supabase PostgreSQL وAuth وStorage وEdge Functions.
- العمل دون إنترنت: Expo SQLite + Drizzle ORM مع Outbox ومزامنة مضبوطة.
- واجهات عربية باتجاه RTL وهوية Light Mode موحدة.
- صلاحيات قاعدة البيانات وRLS هي الحماية الفعلية؛ إخفاء عناصر الواجهة ليس بديلًا عنها.

## مبدأ التنفيذ

يُنفّذ المشروع على مراحل، ولا تنتقل المرحلة إلى التالية قبل اجتياز شروط القبول والاختبارات المحددة في وثيقة الخطة.
