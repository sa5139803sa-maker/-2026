## تطبيق الويب المستقل

يوجد تطبيق Next.js مستقل في `apps/web/`:
- `/platform`: لوحة مدير المنصة، وتعمل فقط لحساب `platform_admin`.
- `/organization`: لوحة مدير المؤسسة، وتعمل فقط لحساب `manager`.
- `/portal`: صفحة بوابة المشترك؛ البحث غير مفعل حتى استكمال رقم الاشتراك الفريد والتحقق الإضافي ومقاومة التعداد.
- `/login`: دخول الإدارة باسم المستخدم أو البريد الإلكتروني.

راجع [دليل تشغيل الويب وأمانه](apps/web/README.md) قبل التشغيل. التطبيق ما زال في مرحلة التنفيذ والاختبار، ولا يوجد نشر إنتاجي أو ملف اعتماديات مقفل بعد.

## القرارات التقنية الأساسية

- تطبيق الهاتف: Expo + React Native + TypeScript.
- لوحة الإدارة وبوابة المشترك: Next.js + TypeScript.
- الخلفية: Supabase PostgreSQL وAuth وStorage وEdge Functions.
- العمل دون إنترنت: Expo SQLite + Drizzle ORM مع Outbox ومزامنة مضبوطة.
- إدارة الحالة: Zustand؛ جلب البيانات: TanStack Query.
- التحقق من المدخلات: Zod + React Hook Form.
- واجهات عربية RTL وهوية Light Mode موحدة.
- حماية البيانات عبر RLS وصلاحيات الخادم؛ إخفاء عناصر الواجهة ليس بديلًا عنها.

## طريقة العمل

1. راجع خطة العمل التنفيذية قبل اختيار المهمة التالية.
2. نفذ نطاقًا صغيرًا قابلًا للاختبار.
3. لا تنتقل إلى مرحلة جديدة قبل اجتياز بوابة المرحلة الحالية.
4. وثق كل إنجاز في `docs/EXECUTION_LOG.md` وحدّث الخطة في نفس Commit.
