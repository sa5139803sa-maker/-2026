# أصول علامة إدارة المياه

تحتوي هذه المجلدات على مسودات SVG متجهية قابلة للتحرير:

- `brand-symbol.svg` — رمز القطرة.
- `brand-logo-ar.svg` — الشعار العربي.
- `brand-logo-en.svg` — الشعار الإنجليزي.
- `brand-logo-horizontal.svg` — النسخة الأفقية.
- `app-icon.svg` — مرجع أيقونة التطبيق.
- `splash-logo.svg` — مرجع شاشة البداية.
- `monochrome-logo.svg` — النسخة أحادية اللون.

**الحالة:** مسودات تنفيذية أولى وليست ملفات إطلاق نهائية. يجب مراجعة الرسم، اتجاه الكتابة، الخطوط، المسافات، والقراءة بأحجام صغيرة قبل اعتمادها.

ملاحظة Android: ملف SVG ليس بديلًا تلقائيًا عن PNG/Adaptive Icon المطلوب في إعداد بناء Expo؛ يجب تصدير نسخة raster صحيحة بعد اعتماد الرمز. لم يُغيّر `app.json` في هذه الخطوة.

الألوان والخطوط المعيارية موجودة حاليًا في `constants/theme/`، مع نقطة تصدير متوافقة في `constants/theme.ts`.

## نسخة PNG للاستخدام في Expo

`app-icon.png` نسخة PNG أولية بدقة 256×256، تم ربطها في `app.json` في إعداد `expo.icon` و`expo.web.favicon`. ملف SVG المصدر ما زال محفوظًا وقابلًا للتحرير. هذه دقة مؤقتة وليست ملف إطلاق عالي الدقة؛ يجب استبدالها بنسخة 1024×1024 وإضافة Android Adaptive Icon قبل اعتماد الإصدار.
