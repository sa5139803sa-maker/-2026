- **التحقق:** لم تظهر نتيجة CI لهذا الالتزام بعد. يتطلب اختبار Supabase الفعلي مشروعًا نشطًا معتمدًا وتفعيل تأكيد البريد.
- **المتبقي:** اجتياز Quality CI، مراجعة تدفق Auth ومعالجة حالات إعادة المحاولة، واختبار sign-up/confirm/sign-in على مشروع تطوير معتمد.
- **قرار القبول:** مرشح مراجعة؛ لا يعتمد قبل CI والاختبار الحي.
