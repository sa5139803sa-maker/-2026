# معاينة إصلاح اعتماديات npm

هذه الوثيقة موجودة مؤقتًا على فرع المعاينة `chore/npm-audit-remediation` فقط لتشغيل تجربة آمنة.

- لا يتم استخدام `npm audit fix --force`.
- لا يتم ترقية Expo SDK أو Expo Router إلى إصدار رئيسي.
- يتم تطبيق الإصلاحات المتوافقة مع نطاقات semver الحالية فقط.
- يتم رفع `package.json` و`package-lock.json` وتقرير audit كـ artifact لمدة قصيرة للمراجعة.
- لا تُدمج ملفات الاعتماديات إلى `main` إلا بعد نجاح `npm ci` وUnit Tests وTypeScript وWeb Export ومراجعة الثغرات المتبقية.

هذه الوثيقة ليست جزءًا من المنتج ولا ينبغي دمجها إلى الفرع الرئيسي.
