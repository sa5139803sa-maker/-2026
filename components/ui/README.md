# مكتبة مكونات الواجهة المشتركة

هذا المجلد يحتوي على نواة أولية لمكونات React Native المشتركة. الهدف تقليل تكرار الواجهات وضمان اتساق الهوية والسلوك وإمكانية الوصول.

## المكونات المتاحة

| المكون | الاستخدام |
|---|---|
| AppHeader | رأس شاشة موحد بعنوان ووصف وعناصر جانبية اختيارية |
| BottomNavigation | شريط تنقل سفلي للهاتف مع عنصر نشط وتسميات وصول |
| WebSidebar | قائمة جانبية للويب مع حالة نشطة وعناصر قابلة للتعطيل |
| Button | زر primary/secondary/ghost/danger مع أحجام وحالة تحميل وتعطيل |
| IconButton | زر أيقونة مع تسمية وصول إلزامية |
| PreviewBanner | تنبيه موحد للصفحات التي تعرض بيانات أو سلوكًا تجريبيًا غير متصل بالخدمات الحقيقية |
| Card | حاوية بطاقة موحدة بحد وظل خفيف |
| AppHeader | رأس شاشة موحد بعنوان ووصف وعناصر جانبية اختيارية |
| SectionHeader | عنوان قسم وإجراء اختياري يعمل عند توفير callback |
| StatusBadge | حالة بنص وأيقونة ولون |
| LoadingState | حالة انتظار |
| EmptyState | حالة عدم وجود بيانات مع إجراء اختياري |
| ErrorState | حالة خطأ مع إعادة المحاولة |
| TextField | حقل إدخال عربي مع مساعد وخطأ وأيقونات وخيارات لوحة مفاتيح |
| TextField | حقل إدخال عربي مع مساعد وخطأ وأيقونات وخيارات لوحة مفاتيح |
| SearchField | بحث مضبوط مع زر لمسح النص |
| SyncIndicator | حالات offline/pending/syncing/synced/error |
| DataTable | جدول أعمدة مرن مع خلايا مخصصة وتمرير أفقي وحالة فارغة |
| ConfirmDialog | نافذة تأكيد قابلة للتخصيص مع حالات التنفيذ والإلغاء |
| SecondaryButton | زر ثانوي مشترك |
| MoneyDisplay | عرض مبلغ مع تسمية عملة صريحة |
| TimeDisplay | عرض مدة بصيغة mm:ss أو hh:mm:ss |

## الاستيراد

```tsx
import {
  Button,
  Card,
  EmptyState,
  ErrorState,
  MoneyDisplay,
  StatusBadge,
  SyncIndicator,
  TimeDisplay,
} from "@/components/ui";
```

## قواعد الاستخدام

- مرر `onPress` حقيقيًا للزر؛ الزر دون callback يعرض معطلًا بدل إيهام المستخدم بأنه ينفذ عملية.
- لا تخترع العملة داخل `MoneyDisplay`؛ يجب تمرير `currencyLabel` من إعداد المؤسسة.
- لا تستخدم لون الحالة وحده؛ يجب أن يظهر النص والأيقونة.
- لا تعرض `synced` إلا بعد تأكيد الخادم، وليس لمجرد وجود اتصال إنترنت.
- استخدم `SyncIndicator` للحالة الفعلية فقط؛ لا تضع حالة ثابتة توحي بالمزامنة.
- المكونات الحالية أساس قابل للتطوير، ولم تُعتمد بعد بعد اختبار البناء والعرض الفعلي على Android والويب.
